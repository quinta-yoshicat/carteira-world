# carteira-world

Página para usar o meu Safe da World Chain (`0xd047…d2B1`) com a chave do dono, por fases.

- **Fase 1 (esta):** só leitura. Mostra dono, assinaturas precisas e saldo; liga a wallet e confirma se é o dono. Não assina nem envia nada.
- Fase 2: enviar um teste pequeno.
- Fase 3: ligar ao Uniswap por WalletConnect.

A chave privada nunca entra na página; quem assina é a wallet (MetaMask / Zerion).
